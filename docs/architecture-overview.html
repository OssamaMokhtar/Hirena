Data Flow: Assessment

👤 User completes 5-step wizard
Step 1: Profile (role, experience, region) → Step 2: Goal (target role, track) → Step 3: Self-rate skills (0-7) → Step 4: AI Skill Analysis (describe experience for rated skills) → Step 5: Review & Submit
⬇️
📤 POST /api/assess
Body: { targetRole, targetTrack, region, selfAssessment: { skillId: level, ... }, aiInferenceInputs: [{ skillId, description }, ...] }
⬇️
⚙️ Route Handler
1. Validate input
2. If aiInferenceInputs present → call inferAllSkills() (OpenAI GPT-4o) → returns { skillId: { level, confidence, reasoning } }
3. Pass input + aiInferenceResults to computeAssessmentResult()
4. Scoring engine merges AI levels over self-assessment, computes weighted scores, identifies gaps/strengths/missing
⬇️
📊 Results Dashboard
Displays: overallScore (0-100), competency area scores with bars, skill ranking (self vs AI-inferred highlighted), top gaps with priority, roadmap actions (immediate / intermediate / long-term), learning resources per gap

Data Flow: Real-Time Interview (Option 2/3)

👤 Candidate starts real-time interview
8-step flow: Greeting → Context → Instruction → Avatar Question → Record Video → Voice Analysis → Facial Analysis → Feedback → Follow-up → Final Result
⬇️
🔌 WebSocket: POST /api/interview/session
Initiates WebSocket connection. Server manages session state machine: awaitingContext → awaitingInstruction → awaitingVideo → analyzingVoice → analyzingFacial → awaitingFollowUp → interviewComplete
⬇️
🎙️ Avatar Mentor
Displays avatar (CSS/SVG animated character + TTS audio). Sends questions based on target role + competency model. Receives candidate responses. Generates follow-up questions.
⬇️
📹 Video Capture
MediaRecorder + getUserMedia captures candidate's video response. Uploads to server for analysis.
⬇️
🔊 Voice Analysis: POST /api/voice/analyze
Analyzes transcription + duration → returns VoiceAnalysisResult: overallQuality, dimensions (confidence, clarity, pacing, emotion, engagement, fillerWords) ✅
⬇️
😊 Facial Analysis: POST /api/facial/analyze
Analyzes video frames → returns FacialAnalysisResult: overallEngagement, dimensions (eyeContact, engagement, confidence, stress, expressiveness, smileWarmth), frames[], emotionDistribution[] ✅
⬇️
🔗 Results Fusion: POST /api/fusion/result
Fuses voice + facial + self-assessment signals with weights (voice 30%, facial 20%, self 25%, content 25%) → returns FusionResult: overallScore, per-dimension breakdown, strengths, gaps, recommendations ✅
⬇️
📊 Interview Results Dashboard
Displays: finalScore, voiceScore, facialScore, selfAssessmentScore, compositeScore, dimensionScores, avatarMessages[], recommendation, nextSteps[], competencyBreakdown

Demo Path (No API Credits Required)

The demo bypasses the OpenAI API entirely.

page.tsx pre-computes a demo result at module load time using computeAssessmentResult(DEMO_INPUT, "demo-user", DEMO_AI_INFERENCE_RESULTS) where DEMO_AI_INFERENCE_RESULTS is seed data (not a real API call). The "See a demo assessment" button sets React state to this pre-computed result and renders the results dashboard. The result is persisted to localStorage (key: hirena-demo-result) so it survives page refresh.

Bypass leverages pre-computed seed data — OpenAI account balance is $0 which triggers 429 when inferAllSkills() runs. Real assessment path still works for self-assessment-only submissions (no aiInferenceInputs) — confirmed: overallScore: 42 returned successfully.

Architecture Decision Record (ADR-001)

📝 ADR-001: Hybrid AI Assessment Model

Status: Accepted

Context: Need to provide accurate skill assessment while minimizing API costs and maximizing demo availability.

Decision: Use hybrid model — self-assessment (0-7 scale) + optional AI inference from text descriptions. Demo uses pre-computed results. Real path uses GPT-4o when credits available.

Consequences: More accurate than self-only. Demo works without credits. AI path requires OpenAI credits ($5-13/interview).

📝 ADR-002: Option 2/3 Real-Time Interview Architecture

Status: Accepted

Context: Need real-time interview practice with multi-modal analysis (voice + facial + content) and avatar mentor.

Decision: Build Option 2/3 components now (APIs + wizard + avatar), use simulated results for demo, upgrade to real services (Deepgram, AWS Rekognition, D-ID) when credits available.

Consequences: Architecture ready for real AI. Demo works with simulation. Upgrade path clear. Cost: $8-26/interview when fully upgraded.

Key design decisions:

  • Hybrid assessment: Self-rating (0-7) + AI inference from experience descriptions — gives both subjective and objective reads
  • Scoring engine is sync: computeAssessmentResult is synchronous — AI calls happen in the route handler before passing results to the engine
  • AI inference is optional: The flow works with self-assessment alone; AI inference adds depth when credits are available
  • MENA-first, global-ready: Regional benchmarks for MENA, APAC, NA, EMEA; bilingual AR/EN
  • PM vertical first: 35 PM skills across 6 pillars; career ladder APM→CPO; expandable to other tracks later
  • Real-time interview (Option 2/3): 8-step flow with avatar mentor, voice + facial analysis, results fusion — APIs built and verified
  • Multi-role competency models: 5 of 14+ roles built (171 skills, 78 pillars), 9 roles in active roadmap. Each role has SKILLS, COMPETENCY_AREAS, LEVELS (0-7), CAREER_LADDER (Junior→Principal/Manager), SKILL_COUNT, PILLAR_COUNT
  • Type system: SkillCategory expanded to 46 categories; Skill.category is string (flexible); CompetencyArea.id is string; CareerLadderStep uses Record<string,number> for expected (flexible internal naming across roles)
